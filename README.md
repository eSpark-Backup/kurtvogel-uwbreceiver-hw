# UWB Based Receiver Design
#### Client Name Kurt Vogel

## Project Requirements
Design should have following features:
- Battery powered. Battery to be selected by Engineering.
- 1 x UWB transceiver (suggestion from client: DW-1000-I-TR13).
- 3 x antennas (to improve accuracy).
- USB-C based charging.
- Suitable Power and Regulation Section.
- Main Microcontroller for processing of data.
- No limit on the PCB size, however ideally it should be small enough as an antenna that it is portable.
- Antennas should be placed in a way to accurately read across a football field. That may mean antennas aren’t SMD but a patch type antenna, that can be placed into a case at the right angles (so maybe three antennas).
